# 宝塔面板部署 liuyushan.top（可视化操作）

> 之前给的 `DEPLOY.md` 是纯命令行版（手改 nginx.conf + systemd）。如果你的 CVM 装了**宝塔面板**，全程不用敲命令行、不用动配置文件，跟着下面点就行。

## 前提
- 腾讯云 CVM 已装宝塔面板（装好后会给你面板地址、用户名、密码）
- 阿里云控制台：把 `liuyushan.top` 的 A 记录指向 CVM 公网 IP（部署前后都行，最后验证前确保已生效）

---

## 第 1 步：上传代码
1. 宝塔左侧「**文件**」→ 进入 `/www/wwwroot/`
2. 本地把 `liuyushan_site` 文件夹压缩成 `liuyushan_site.zip`（右键 → 发送到 → 压缩）
3. 宝塔文件管理器里点「**上传**」→ 传 zip → 上传完右键「**解压**」到 `/www/wwwroot/liuyushan.top/`
   - 最终路径：`/www/wwwroot/liuyushan.top/liuyushan_site/backend/server.js`
4. ⚠️ 以后**别整包覆盖** `liuyushan_site/backend/data/`（那里存新生墙/弹幕，覆盖会清空）

## 第 2 步：装 Node.js
1. 宝塔「**软件商店**」→ 搜「**Node.js 版本管理器**」→ 安装
2. 装好后打开它 → 安装一个 Node 版本（推荐 **18.x 或 20.x LTS**）
3. 记下命令行路径，一般是 `/www/server/nodejs/v18.x.x/bin/node`（守护要用）

## 第 3 步：让后端一直跑（进程守护）
推荐用宝塔自带的「**Supervisor 管理器**」（软件商店搜 Supervisor 安装），也可以用 PM2：

**方式 A：Supervisor（最稳，推荐）**
1. 软件商店 → 安装「**Supervisor 管理器**」
2. 打开 →「**添加守护进程**」
   - 名称：`haust-site`
   - 运行目录：`/www/wwwroot/liuyushan.top/liuyushan_site/backend`
   - 启动命令：**`bash /www/wwwroot/liuyushan.top/liuyushan_site/backend/start.sh`**
   - 进程数量：1
3. 点「确定」→ 状态变「运行中」就 OK（崩了自动重启、开机自启）

> ⚠️ 启动命令**不要**直接写 `node server.js`——Supervisor 环境里找不到 node。用 `start.sh`（已自动探测宝塔 node 路径），不用手写版本号。
> 若服务器上还没有 start.sh：宝塔「终端」粘贴 `cat > /www/wwwroot/liuyushan.top/liuyushan_site/backend/start.sh <<'EOF' ... EOF` 一段即可生成（脚本内容见 backend/start.sh）。

**方式 B：PM2**
1. 软件商店 → 安装「**PM2**」
2. 「PM2 管理器」→「**添加项目**」
   - 项目目录：`.../backend`
   - 启动文件：`server.js`
   - 勾选「开机启动」
3. 点启动

## 第 4 步：添加站点 + 反向代理（核心）
1. 宝塔「**网站**」→「**添加站点**」
   - 域名：`liuyushan.top`
   - 根目录：`/www/wwwroot/liuyushan.top/liuyushan_site/frontend`（随便填，反正走反代）
   - PHP 版本：选「**纯静态**」
   - 不建数据库
2. 添加好后点进该站点 →「**反向代理**」→「**添加反向代理**」
   - 代理名称：`haust`
   - 目标 URL：`http://127.0.0.1:3000`
   - 发送域名：`$host`
   - 其余默认
3. 点「提交」。现在访问 `liuyushan.top` 会被转发到 Node 服务（前端 + `/api` 都在 3000 上）

> 说明：Node 的 server.js 自己就会托管 frontend 静态文件，所以**反代到 3000 就够了**，宝塔不用再单独管静态文件。

## 第 5 步：SSL 证书（去掉"不安全"）
1. 站点 →「**SSL**」→「**Let's Encrypt**」
2. 勾选 `liuyushan.top` → 点「**申请**」（免费 DV 证书，自动续期）
3. 申请成功后 → 打开「**强制 HTTPS**」

## 第 6 步：验证
1. 阿里云确认 A 记录已指向 CVM IP，等几分钟生效
2. 浏览器开 `https://liuyushan.top`，按 **Ctrl+F5** 强刷
3. 试一下：新生墙填表→上墙、发弹幕、点西苑卡片跳转推文

---

## 常见坑
| 现象 | 原因 / 解决 |
|---|---|
| 打开是旧站 / 空白 | DNS 未生效或浏览器缓存 → 等几分钟 + Ctrl+F5；确认 A 记录指向新 IP |
| 502 Bad Gateway | Node 没起来 → 去 Supervisor/PM2 看进程状态、看 `backend/data/server.log`；确认端口是 3000 |
| 弹幕 / 新生墙不存 | API 没通 → 确认反代目标 `127.0.0.1:3000`、Node 在跑 |
| 证书申请失败 | 域名没解析到这台服务器 / 80 端口被占 → 先确认 A 记录生效、关掉其他占 80 的服务 |
| 白屏 | 看浏览器 F12 控制台报错；多半是静态资源 404（路径问题） |

## 以后更新前端
只改了 `frontend/` 里的文件 → 只把 `frontend/` 重新上传覆盖即可，**不用重启 Node**。改了 `backend/server.js` 才需要重启守护进程。
